# Форма проверки операции для @insaidersberbot

Статическая страница мини-аппа Telegram. Исходник лежит в приватном репозитории бота (`bot/webapp/index.html`), сюда копируется только для публикации на GitHub Pages.

Страница не содержит токена и данных пользователей: признак и запрещённые периоды бот передаёт в ссылке, ответы форма отправляет боту через `Telegram.WebApp.sendData`, решение выносит бот.
